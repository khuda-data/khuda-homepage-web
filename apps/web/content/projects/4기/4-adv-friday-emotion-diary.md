NLP 트랙에서 배운 감정 분석과 문장 생성을 외부 API 없이 직접 구현하는 것이 목표였다. KoBERT를 15개 감정으로 파인튜닝하고, 약 17만 쌍의 대화 데이터에 감정 라벨을 넣어 KoGPT2가 답변을 생성하도록 학습했다.
